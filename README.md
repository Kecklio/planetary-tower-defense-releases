# Planetary Tower Defense: downloads

The finished game, ready to play on Windows. (The game's code isn't here.)

## Playing

1. Open **[Releases](https://github.com/Kecklio/planetary-tower-defense-releases/releases/latest)** and download the zip under the newest version.
2. Unzip it anywhere.
3. Double-click `PlanetaryTowerDefense.exe`. `HOW-TO-PLAY.txt` beside it has the controls.

Your universes are saved separately (in `%APPDATA%\LOVE\PlanetaryTowerDefense`), so a new version can go in a new folder and still find them.

## Versions

Each version is named after the last change that went into it: **a55** is everything up to change #55.
